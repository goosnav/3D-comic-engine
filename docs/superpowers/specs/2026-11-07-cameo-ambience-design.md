# Cameo focus and awkward ambience

User request: cameos should optionally get their own scene, standing still or walking with the camera following. Add subtle background ambience (including laundromat), suitable for awkward silence without overpowering speech. Edit and push. No deployment requested this turn.

Builder choices: add a `cameo` row to the existing sequence, selectable through Add cameo shot. Schema: `{cameo:"goose", behaviour:"stand"|"walk", camera:"static"|"follow", seconds:3}`. Defaults: stand/static/3 seconds; range .3–30. Any catalog cameo is selectable and auto-included in the timeline asset list. Script extras remain the independent background selection. Existing background extras remain unchanged outside focus rows. Focus rows show only the selected cameo, centered in a dedicated foreground lane; the regular cast/book and other cameos are hidden for the cut and restored on the next beat. Stand uses an idle clip/pose. Walk moves deterministically over a short path; follow translates the camera with it, static fits the entire path. Preserve finite transforms, seeking, all aspect ratios, CPU/WebGL parity. A cameo-only sequence uses an ordinary book-free template with only cameo rows.

Ambience: optional `ambience:{mode:"auto"|"off"|"room"|"laundromat",volume:0.35}`. Omitted means auto. Auto chooses a quiet room hum and is suppressed when music is attached; explicit presets may accompany music. Volume 0–1, never amplifies speech, and ambience is ducked during measured speech with smooth transitions and fade-in/out. Generate deterministic original ambience locally in shared JS, no external downloads, recordings, licenses or network dependency. Browser and CLI mix the same samples. Preserve supplied music, speech, captions and portable-job configuration. Expose mode and volume in the export GUI, Off restores actual silence.

Preserve unrelated pre-existing audio-security edits and exclude them from the push.
